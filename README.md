# Ashwini Vinyasam Website

A modern, fully responsive business website built with Next.js, TypeScript, and Tailwind CSS.

## Features

- 🎨 Modern, clean UI design with smooth animations
- 📱 Fully responsive on all devices
- ⚡ Built with Next.js 14 App Router
- 🎯 TypeScript for type safety
- 💅 Styled with Tailwind CSS
- 🎭 shadcn/ui components
- 🖼️ Dynamic image loading from Unsplash

## Pages

- **Home** - Hero section, services preview, and company overview
- **About Us** - Company story, vision & mission, team section
- **Services** - Comprehensive service offerings with detailed cards
- **Gallery** - Masonry-style image gallery with lightbox
- **Contact** - Contact form and business information

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

### Build

```bash
npm run build
npm start
```

## Technologies Used

- Next.js 14
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide React (icons)
- Unsplash (images)
