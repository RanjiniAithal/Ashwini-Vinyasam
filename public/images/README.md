# Image Directory Structure

Place your images in the following folders:

## `/hero/`

Hero/banner images for each page:

- `home-hero.jpg` - Home page hero background (recommended: 1920x1080px)
- `about-hero.jpg` - About page hero background (recommended: 1920x600px)
- `services-hero.jpg` - Services page hero background (recommended: 1920x600px)
- `gallery-hero.jpg` - Gallery page hero background (recommended: 1920x600px)
- `contact-hero.jpg` - Contact page hero background (recommended: 1920x600px)

## `/services/`

Service card images (recommended: 600x400px):

- `business-consulting.jpg`
- `digital-marketing.jpg`
- `innovation-strategy.jpg`
- `web-development.jpg`
- `brand-strategy.jpg`
- `ui-ux-design.jpg`
- `cloud-solutions.jpg`
- `cybersecurity.jpg`
- `data-analytics.jpg`
- `hr-consulting.jpg`
- `process-automation.jpg`
- `international-expansion.jpg`
- `mobile-app.jpg`

## `/team/`

Team member photos (recommended: 400x400px):

- `team-member-1.jpg`
- `team-member-2.jpg`
- `team-member-3.jpg`
- `team-member-4.jpg`

## `/gallery/`

Gallery images (various sizes for masonry layout):

- `gallery-1.jpg` through `gallery-15.jpg` (or more)

## `/about/`

About page images:

- `office.jpg` - Office/workplace image (recommended: 800x1000px)
- `about-preview.jpg` - About preview section (recommended: 800x1000px)

## `/contact/`

Contact page images:

- `office-building.jpg` - Office building exterior (recommended: 800x400px)
- `map.jpg` - Map/location image (recommended: 1600x600px)

## Root `/images/`

- `logo.png` - Your Ashwini Vinyāsam logo (transparent PNG recommended)

---

**Note:** After adding images, update the image paths in the code from Unsplash URLs to local paths like `/images/hero/home-hero.jpg`
